**Kept for the record.** An early version from 2026-10-15, before the one-click `BUILD.bat` (v26). To play, use the newest release.

**Bug descriptions, versioned reports, fullscreen menu bar**

- F10 captures the report, then opens a box to describe the bug
  (description.txt in the report).
- Version number (runtime/version.h) in report folder names, info.txt,
  the title bar and About.
- Fullscreen: the menu bar appears with the mouse at the top edge;
  Alt+Enter toggles fullscreen; Esc leaves fullscreen.

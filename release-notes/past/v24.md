**Kept for the record.** An early version from 2026-10-16, before the one-click `BUILD.bat` (v26). To play, use the newest release.

**DQVC's weekly stock on the original calendar**

The download files are decoded: RC4 with the key "XENLONPROJECTKEY"
(the game's code name), then 4 bytes that make the whole encrypted
file, read as one big-endian number, divisible by 0xC2A030D4 (overlay
23, 021f6324). A DQVC stock file is a pool of item records (item,
price, quantity); the game shows six, picked per player.

The built-in server now builds and seals each week's stock from
wfc/YDQE/dqvc.txt: the 52 sales the original service ran every year
from July 2010 to 2014, each starting on its original date, chosen by
the PC's clock. tools/dqvc_build.py makes the schedule from pages
saved from yab's DQ9 Tools (1,352 items; ids from the open-source DQIX
save editor); the schedule itself, like the other download files, is
kept out of git.

Tested in the game on three dates: Dragon Extravaganza, Winter Fayre
and DQVC Fashion Week stock, from generated files.

DQIX_RAMDUMP and a key dump in DQIX_TRACEFN for debugging.

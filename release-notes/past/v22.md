**Quiet the ARM7's BIOS writes; mark Wiimmfi as not for DQIX**

The first real connection test reached Nintendo's own servers through
Wiimmfi's DNS (error 20110, service discontinued), so Wiimmfi doesn't
host DQIX; AltWFC (172.104.88.237) is the one the 2022 guides used.

The SDK's wireless code writes through an unset pointer into the ARM7
BIOS while connected; the DS ignores those writes. Log the first only,
so reports keep the network lines.

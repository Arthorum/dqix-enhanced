**Kept for the record.** A nightly version from 2026-10-18: the newest work of its day, less tested. To play, use the newest release.

**DQVC in sessions, host window, DS Lite photo by default**

Sessions use the built-in Wi-Fi for every console: the host's wfc files go
out with the start message, the virtual network is sealed (built-in server,
DHCP and ARP only, game-time clock, the server's own random numbers), so
every PC computes the same. A DQVC purchase in a 2-PC session stayed in sync.

Windows: a host / join window with the address, a Copy button, the players
who joined, Start the game and Cancel. The DS Lite photo is the default
console until the player picks one. Long message boxes are wrapped.

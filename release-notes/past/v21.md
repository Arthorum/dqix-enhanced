**Kept for the record.** An early version from 2026-10-15, before the one-click `BUILD.bat` (v26). To play, use the newest release.

**Wireless chip, access point and internet connection**

The DS wireless chip is emulated (a C port of melonDS's Wifi.cpp and
WifiAP.cpp), so the game's connection attempts no longer hang: with
no connection it fails like a DS with no access point, and Sellma
offers DQVC offline.

Wireless menu: "Connect to the internet" runs the virtual access
point DQIX-PC through libslirp (vendored, BSD) with the DS's DNS set
to a community Nintendo WFC replacement (AltWFC by default, Wiimmfi,
or wfc_server in settings.ini). Each install makes up its own MAC.
The offline DLC unlock moved here from the Game menu.

Bug reports record the wireless setting, the MAC, the Wi-Fi settings
area and each network step (DHCP, DNS answers, connections).

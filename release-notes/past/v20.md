**Kept for the record.** An early version from 2026-10-15, before the one-click `BUILD.bat` (v26). To play, use the newest release.

**Downloadable quests and special guests**

Game > Downloadable quests and special guests: at start, sets the unlock bit
of the 64 downloadable quests and the 23 special-guest bits in each valid
save slot and recomputes the slot's three CRC-32s (layout from the
open-source DQIX save editor). Applied before the game reads the save and to
the boot copy kept for bug-report replays.

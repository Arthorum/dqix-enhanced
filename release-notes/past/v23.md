**Kept for the record.** An early version from 2026-10-16, before the one-click `BUILD.bat` (v26). To play, use the newest release.

**Built-in Nintendo Wi-Fi Connection server (offline Sellma downloads)**

The community servers no longer serve DQIX, so the PC answers the game
itself (runtime/wfc.c), with nothing going to the internet:

- DNS: *.nintendowifi.net -> a virtual server address
- a small TCP responder for that address (one HTTP/1.0 request per
  connection), in front of libslirp
- conntest, the login server (acctcreate, login, svcloc) and the
  download server (count, list, contents) from wfc/<game code>/:
  DQIX's downloads as Nintendo last served them, preserved by the
  community (InternalLoss/DLS1-Files); kept out of git
- like the community's NoSSL patches, the network library's https://
  login and download addresses are switched to http:// in memory
- replies carry a Date header: Nintendo's login code needs it

Tested on the Sellma replay with the 393-hour save: "Downloading data",
"New quests are now available", DQVC's downloaded stock, and all 64
downloadable quests switched on in the save.

Server > Built-in is the new default.
